# 01 · 产品说明

> 本文回答：为谁做、解决什么问题、核心场景长什么样、交互上坚持什么原则。

## 1. 问题定义

游戏是表达欲最强的内容形态，也是制作门槛最高的之一：

| 环节 | 传统门槛 |
| --- | --- |
| 策划 | 需要懂玩法设计、数值、文档写作 |
| 开发 | 需要编程与引擎（Unity / Unreal / Godot） |
| 美术 | 需要绘画、建模、动效能力 |
| 测试 | 需要工程化的用例与工具 |
| 发布 | 需要打包、签名、商店审核 |
| 运营 | 需要数据分析与持续更新 |

每一环都挡住了 99% 有创意的普通人。通用 AI 编程工具（如 Cursor）服务的是程序员，产出代码；普通人需要的不是代码，而是**一个能玩、能上线的作品**。

**Waypoint 的答案**：垂直切入游戏开发，把整条流水线 Agent 化，用户只需要会聊天。

## 2. 目标用户

### 主用户：有创意的普通人（第一优先）

- 玩家、学生、内容创作者、社群组织者
- 特征：零编程 / 零美术基础，有明确的玩法想法或想复刻喜欢的游戏
- 诉求：「把我脑子里的游戏做出来，能玩、能发给朋友」

### 次用户：独立游戏爱好者

- 有少量技术或设计基础，缺的是「一支团队」
- 诉求：用 Agent 团队补齐自己不擅长的环节，提升产能

### 三类用户：小团队 / 工具向用户（远期）

- 微型团队用 Waypoint 做原型验证与内容量产
- 不作为前中期设计重心

## 3. 用户价值主张

> **「你会聊天，就会做游戏。」**

1. **零门槛**：不用学编程与美术，学习成本控制在 10 分钟新手引导内。
2. **有团队**：制作人、策划、开发、美术、测试、运维、运营七个角色随时待命。
3. **见效快**：第一次对话就能得到可玩的小游戏，反馈以分钟计。
4. **能上线**：不是 Demo 玩具，产出具备核心玩法闭环、可直接发布的作品。

## 4. 核心用户故事

1. **从 0 到玩**：作为一名普通玩家，我想在手机上描述「做一个太空题材的放置养成游戏」，10 分钟后得到一个能玩、能存档的原型，这样我能立刻判断好不好玩。
2. **指挥团队**：作为一名用户，我想只说「角色不够可爱、战斗太慢」，制作人格自动把我的反馈翻译成美术与策划任务并跟踪完成，而我不需要知道背后怎么分工。
3. **关键决策**：作为一名用户，当玩法或美术有重大分叉时，我希望团队给我 2-3 个可试玩的选项让我拍板，而不是替我瞎做。
4. **一键上线**：作为一名用户，作品完成后我希望点一下「发布」，运维格局位处理好构建与上架，给我一个可以分享的链接。
5. **持续经营**：作为一名创作者，我希望上线后运营格每周告诉我数据怎么样、玩家在骂什么、下一步建议改什么。

## 5. 核心场景走查

### 场景 A：第一次使用（上手 10 分钟）

1. 打开 APP → 选择「从模板开始」或「描述你的想法」
2. 输入一句话想法 → 制作人主动追问 2-3 个关键问题（题材 / 玩法偏好 / 美术风格三选一）
3. 团队开工，屏幕上实时滚动各角色的工作动态
4. 几分钟后，可玩的 Web 游戏出现在预览区，用户立刻试玩
5. 试玩后一句反馈 → 进入迭代循环

### 场景 B：日常迭代（手机碎片时间）

- 通勤路上收到「每日进展」推送：昨天反馈的 3 个问题已修复 2 个
- 打开手机试玩新版本，语音输入反馈，继续推进
- 回到桌面端，在看板上查看细节与资产变更

### 场景 C：上线与经营

- 用户点击「发布」→ 运维格执行构建流水线，输出可分享的 Web/H5 链接（远期：应用商店）
- 运营格局接手：产出首周数据报告与迭代建议，驱动下一轮循环

## 6. 交互设计原则

| 原则 | 含义 |
| --- | --- |
| 对话即指挥 | 对话框是唯一必需的入口；所有高级功能（看板、资产库）都是对话的可视化投影，不是第二套操作体系 |
| 所见即所玩 | 一切产出落在可运行的预览里；不存在「看不见的进度」 |
| 最少决策 | 用户只在对体验有实质影响的节点做选择，且每个决策点必须给出可试玩的选项，而不是文字描述 |
| 过程透明 | Agent 团队在做什么、为什么这么做、花了多少额度，永远可见、可追溯 |
| 可回滚 | 每次变更形成版本；任何「改坏了」都能一键回到上一个好版本 |
| 失败友好 | 生成失败不展示堆栈，展示人话原因与重试 / 降级方案 |

## 7. 范围边界（第一阶段 Non-Goals）

- ❌ 不做通用编程工具（对标 Cursor 的编辑器形态）
- ❌ 不做 3A / 大型 3D 品类的完整支持，第一阶段聚焦轻量品类：放置、卡牌、文字冒险、休闲小游戏、互动叙事
- ❌ 不做「全自动无人参与」：关键决策永远留给用户
- ❌ 不做游戏发行平台（远期再评估）

## 8. 成功指标（北极星与护栏）

- **北极星**：每周「从想法到可玩游戏」完成的用户数（Idea-to-Playable）
- 辅助指标：首次成功时长（目标中位数 < 10 分钟）、7 日留存、迭代轮次 / 项目
- 护栏指标：单项目 Token 成本、生成成功率、用户主动中止率
